Learn every line before the defense

A 7-session plan, about 2 hours each, that takes you from “what is machine learning?” to rewriting the training program from memory and answering any evaluator question.

Why this matters The subject's AI chapter is explicit: you must be able to explain and defend every decision. If an AI wrote code you cannot explain, you fail the defense. This plan gets you from “it works” to “I understand it and could rebuild it alone.” The last session is a full rewrite without looking.

Session 1 The problem and the data~1.5 h

Goal: understand what you are predicting, why it is called “learning”, and what the data looks like.

Check yourself

Is this supervised or unsupervised learning? Regression or classification? Why?
Supervised (every row comes with the correct price) and regression (the output is a continuous number, not a category).

Session 2 Hypothesis and cost function~2 h

Goal: know exactly what θ0 and θ1 mean and how we measure how bad a line is.

Check yourself

What are the units of θ0 and of θ1? θ0 is a price (price at 0 km). θ1 is price per km, so it is tiny: about −0.0214, meaning a car loses roughly 21 units of price per 1 000 km.

Session 3 Gradient descent~2.5 h

Goal: derive the two subject formulas yourself and understand the learning rate and the simultaneous update.

Check yourself

Why is there a minus sign in the update θ := θ − α·gradient? The gradient points uphill (towards higher cost). We want to go downhill.

Session 4 Feature scaling~2 h

Goal: understand the one design choice evaluators always ask about: why we normalize, and how the thetas are converted back.

Check yourself

Does normalizing break the rule “use the specified training function”? No. The update formula is exactly the subject's. We only change the units of the input before training, which is standard practice. predict.py still uses θ0 + θ1·mileage on raw km.

Session 5 The code, line by line~2 h

Goal: be able to explain any line an evaluator points at.

Session 6 Bonus: precision and plotting~1.5 h

Goal: understand the metrics well enough to say whether the model is good.

Session 7 Rebuild and mock defense~2.5 h

Goal: prove to yourself that you could have written this project alone.

Quick commands

# install dependencies (once)
uv sync

# mandatory part
uv run predict.py          # before training: prints 0.00
uv run train.py            # learns theta0, theta1 and writes thetas.json
uv run predict.py          # now gives a real estimate

# bonus
uv run plot.py             # data + regression line
uv run precision.py        # MAE, MSE, RMSE, R^2

# tests
uv run pytest -v
