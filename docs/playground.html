Manual mode

Move the line yourself and try to beat gradient descent. Moving a slider replaces the current thetas; press Step afterwards to let gradient descent continue from there.

Best possible: θ0 ≈ 8 499.60, θ1 ≈ −0.021449, cost ≈ 222 822.62.

Experiments to try

  1. Normal run. α = 0.1, normalized. Press Run. The cost drops fast and flattens out within about 100–200 iterations.
  2. One-step magic. α = 1, normalized, press Step once. You land exactly on the minimum. (Why?)
  3. Oscillation. α = 1.9. The line jumps from one side to the other but still settles.
  4. Divergence. α = 2.1. Every jump overshoots more than the last and the cost explodes.
  5. Too slow. α = 0.01. It works, but it needs many more iterations.
  6. No normalization. Untick “Standardize”, set α = 1e-10 and run. θ0 hardly moves from 0, and the line rotates to a wrong, rising slope. Then try α = 1e-9: it diverges.
  7. Start somewhere else. Put the line somewhere silly with the sliders, then run. It always ends at the same minimum, because the cost is a bowl with one bottom.
